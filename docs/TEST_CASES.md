# Test Cases Specification (`antigravity-mcp-manager` `v2.0.0`)

**Languages:** **English** | **[한국어 섹션 바로가기](#테스트케이스-명세-국문)**

This document defines the pre-implementation test cases and verification oracles for `antigravity-mcp-manager` `v2.0.0` (`Rev 6`, Approved Pre-Design Audit `5095348c`), executed via `npm test` (`node scripts/build.js && node scripts/run-tests.js`).

## Test Environment & Runner

- **Runner**: `node scripts/build.js && node scripts/run-tests.js` (recursively collects `test/**/*.test.js` and runs via Node.js `node:test` + `node:assert/strict` across all Node 20.x releases and OSs)
- **CI Matrix**: `ubuntu-latest`, `windows-latest`, `macos-latest` (`.github/workflows/ci.yml`)
- **Layered Test Suites**:
  - `test/core/*.test.js` — Vendor-independent domain core (`0` host/DOM/timer/vendor globals), pure `DisposableStore`, `Promise.all`-safe FIFO `AsyncMutex` with `lockToken` & `parentToken`, `sha256` CAS, UTF-16 JSONC codec, raw Split-URL/ambiguous-transport rejection, post-merge security guards, single-CAS `applyAuthToAllHttp`, and `McpManagerService`
  - `test/security/*.test.js` — Pure HTTPS dot-boundary origin validation, credential-free loopback `http:` external auth URL policy, parameterized iterative percent-decoded CDN path confinement (`%252e%252e`), and scoped one-shot W3C `TrustedTypes` / CSP `nonce` guards
  - `test/adapters/*.test.js` — Antigravity raw-text ports (0-byte `""` `FOUND` preservation, Go/Node `ENOENT` vs HTTP `404`/`Instance not found` separation, `revealConfigInExplorer`), Fiber/Remote RPC, companion coordinator (`1500ms` retry cancellation), 6-state remote workbench FSM (`PASSIVE_ATTACHED` & `ROLLED_BACK`) & WebIDL-bound `[Replaceable]` `self`/`origin` + `URL.canParse` + `syncCaptureStack` CDN Worker bridge, native DOM integrator (`localStorage` plaintext backup purge & Settings tab-leave secret scrubbing)
  - `test/ui/*.test.js` — Zero-HTML-sink UI views, all-`stdio`/`command` & `PATH` confirmation gate, `INVALID_JSON` broken raw text recovery, modal focus trap & injected disconnected-trigger focus fallback, Korean IME composition guard (`isComposing || keyCode === 229`), responsive CSS, and `scrollTop` preservation
  - `test/scripts/*.test.js` — Dual-bundle CJS bundler (`dist/mcp_manager_autoinject.js` + synthetic `entryModule` `require.main`-preserving standalone `dist/ensure_statusbar_patch.js`), companion-preserving `--uninstall` vs sole-plugin `--uninstall`, bidirectional Stage 2 -> Stage 1 ASAR reverse rollback (`restoreAsarOnDisk` <-> `patchAsarOnDisk`), dedicated `--restore` 3-check pre-verification (`RESTORE_VERSION_MISMATCH`, `RESTORE_BACKUP_MISSING`, `ASAR_LOCKED`), RFC 6455 WebSocket, and lock discipline
  - `test/e2e/*.test.js` — Real headless Chromium/Edge E2E: strict `base-uri 'self'` + `require-trusted-types-for 'script'` workbench promotion (`MCP-TC-038`), live `https://antigravity.google.com` unmodified HTTP CSP with single-URL CDP `Fetch` local `v2.0.0` bundle verification (`MCP-TC-041`), 3-plugin coexistence (`MCP-TC-048`), and real-browser `AUDIT-M1`–`M4`/`M6` failure injection (`MCP-TC-049`)
- **Isolation Policy**: All file-based and headless browser tests run inside isolated temporary directories (`D:/codex/build/antigravity-mcp-manager-v2/` on local Windows when available, falling back to `os.tmpdir()` on CI) without modifying live host global files (`~/.gemini/antigravity` or `app.asar`).

## 테스트케이스 명세 (국문)

본 문서는 사전 설계 독립 감사 `Gate: PASS`(`5095348c`, `Rev 6`)로 확정된 `antigravity-mcp-manager` `v2.0.0`(벤더 독립 육각형 아키텍처)의 공개 진입점 및 계층별 검증 사례와 합격 판정 기준(Oracle)을 정의합니다.

- **실행 명령**: `npm test` (`node scripts/build.js && node scripts/run-tests.js`)
- **CI 매트릭스**: `ubuntu-latest`, `windows-latest`, `macos-latest` 3대 운영체제 검증
- **계층 구성**:
  - `test/core`: 코어 순수성(식별자·벤더 브랜드 0건), 순수 `DisposableStore`, `Promise.all` 안전 FIFO `AsyncMutex`(`lockToken`/`parentToken`), `sha256` CAS(`CONFLICT`), UTF-16 JSONC 코덱, 원시 Split-URL 선차단·인증 병합 후 보안 게이트, 단일 CAS `applyAuthToAllHttp`, 보상 롤백 3분기 재동기화
