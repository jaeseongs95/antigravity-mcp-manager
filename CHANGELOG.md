- **BREAKING — Migrated to `AddonManifest.v2` (`antigravity-native-addon-host` `v2.3.0+`) & Removed `AUX_PANE` Sidecar / `app.asar` / `mainHook`**:
  - Removed `sidecars/` (`AUX_PANE` **플러그인 > MCP Manager** pane), `scripts/install-settings-menu.mjs`, `scripts/electron-hook.cjs`, `@electron/asar` dependency (now **0 runtime npm dependencies**), and legacy `install:settings` / `uninstall:settings` / `status:settings` scripts.
  - Upgraded `addon-manifest.json` to `AddonManifest.v2` (`schemaVersion: 2`, `trustLevel: "trusted"`, `compatibility: { hostProfile: "antigravity-desktop", minHostVersion: "2.3.0" }`, `capabilities: ["renderer"]`, `configBridge.scopes` declaring `antigravity:mcp-config` (`rw`), `antigravity:plugin-mcp-configs` (`ro`), and `antigravity:mcp-config-legacy` (`ro`), 4 non-exclusive `addon-owned-slot` entries: `settings-nav` `shadow: false`, `pane` / `customizations-btn` / `customizations-overlay` `shadow: true`, `storageNamespace: "antigravity-mcp-manager"`, `ipcChannelPrefix: "mcp-manager:"`, `loadOrder: 60`). Requires `addon-host trust approve antigravity-mcp-manager` (SHA-256 pinning in `~/.gemini/antigravity/trust-policy.json`).
  - Added full native Shadow DOM MCP Manager CRUD panel (`native-mcp-panel.mjs`) and `HostBridgeConfigStore` (`host-config-store.mjs`) powered directly by `antigravity-native-addon-host` `v2.3.0+` Option A **Named-Scope Config Bridge** inside both **Settings → MCP Manager** and the **Customizations → MCP Manager** centered popup modal, while preserving an EN/KO Config Bridge guide fallback and late `SidecarBridge` URL upgrade path when no bridge is attached.
- **Fixed `config-bridge.js` Real Contract & Authoritative CAS Compatibility**:
  - Updated `host-config-store.mjs` to handle `config-bridge.js`'s real payload contract (`status: 'ok'` returns `rawText: null` + parsed `data` + on-disk `sha256`; `status: 'corrupt'` returns `rawText`) across global, plugin, and legacy scopes, and mapped `ERR_CONFIG_BACKUP_SYMLINK_FORBIDDEN` to `WRITE_JAIL_VIOLATION`.
  - Updated `src/core/manager-service.mjs` (`resolveAuthoritativeSha256`) across all 5 `readGlobalConfig()` paths (`getSnapshot`, `upsertServer`, `toggleServerDisabled`, `deleteServer`, `saveRawJson`) to preserve authoritative on-disk `sha256` digests so CRLF / non-canonical JSON files pass CAS without `ERR_CONFIG_CAS_CONFLICT`.
- **Refactored (SOLID 0순위)** renderer into cohesive SRP/OCP/LSP/ISP/DIP modules under `src/adapters/antigravity/renderer/` (`host-runtime.mjs`, `host-config-store.mjs`, `native-mcp-panel.mjs`, `addon-styles.mjs`, `settings-sidebar-mount.mjs`, `customizations-mount.mjs`, `mount-coordinator.mjs`) + zero-dependency deterministic assembler (`scripts/build-renderer.mjs` → `src/adapters/antigravity/addon-renderer.js`, zero unsafe DOM sinks).
- **Added** host UI language auto-detection (Korean vs English) + `storageNamespace` language persistence (`antigravity-mcp-manager:lang`) with automatic 1-time migration from legacy `agy-mcp-manager-lang`.
- **Stabilized CI & Tests**: Verified all 30 tests (`NMCP-TC-001`–`NMCP-TC-032`) covering `AddonManifest.v2` schema & manifest-to-scope parity, SOLID build parity, Shadow DOM Option B2, `openModal` + `PortalArbiter`, Named-Scope Config Bridge (`rawText: null` on `ok`, CRLF on-disk `sha256` CAS, `corrupt` Raw JSON recovery), no-bridge fallback + late URL upgrade, and `addonHost.dispose()` teardown.

## 2.1.0 — Native Settings Left-Sidebar Menu Integration & Built-In EN/KO Switcher
- **Added** `src/adapters/antigravity/desktop-server.mjs`: standalone loopback HTTP server reusing 100% of verified `v2.0.0` core (`McpManagerService`), write-jailed FS store, and hardened HTTP security middleware (`127.0.0.1:0` + 256-bit random session token).
- **Added** `src/adapters/antigravity/settings-menu-injector.js`: zero-unsafe-DOM-sink renderer injector that inserts a native-styled **MCP Manager** item directly below **Browser** (or Korean **브라우저**) in Antigravity 2.0's Settings left sidebar with 0px layout shift, preserves the native top-right `X` close button, syncs host font/theme, and toggles the embedded UI iframe without destroying native React nodes.
- **Added** built-in **English / Korean (`EN | 한국어`)** language switcher inside the MCP Manager UI with cross-restart persistence via origin/source-validated `postMessage` to the Antigravity host renderer `localStorage`.
- **Added** `scripts/electron-hook.cjs` & `scripts/install-settings-menu.mjs` (`--install` / `--uninstall` / `--status`) using official `@electron/asar` with an independent marker (`AGY_MCP_MANAGER_SETTINGS_V2`), automatic backup preservation, and zero coupling to `statusbar_autoinject.js`.
- **Polished** Settings-native UI (`host-settings-mode`): 2-column horizontal server rows, segmented `Servers | Raw JSON` pill, crisp `+ Add Server` CTA, collapsible `Quick Paste JSON / URL`, and cleaner `HTTP` / `Stdio` transport badges.
- **Added** comprehensive v2.1.0 tests (`NMCP-TC-021`–`NMCP-TC-026`): real Chromium CDP E2E, `@electron/asar` round-trip & edge cases, `desktop-server.mjs` security & CRUD lifecycle, 100% EN/KO `I18N` dictionary parity, and untrusted `postMessage` rejection (26/26 PASS).
