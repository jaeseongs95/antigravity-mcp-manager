# Changelog

## 3.0.0 — `AddonManifest.v1` Migration, SOLID Renderer Modularization & Customizations Integration
- **BREAKING — Removed direct `app.asar` patching**: Removed `scripts/install-settings-menu.mjs`, `@electron/asar` dependency (now **0 runtime npm dependencies**), and `install:settings` / `uninstall:settings` / `status:settings` scripts. Host installation and `app.asar` lifecycle are delegated exclusively to `antigravity-native-addon-host` (`v1.0.1+`).
- **Added** `addon-manifest.json` (`AddonManifest.v1`, `capabilities: ["mainHook", "renderer"]`, `compatibility: { hostProfile: "antigravity-desktop", minHostVersion: "1.0.0" }`, 4 non-exclusive `addon-owned-slot` declarations: `settings-pane`, `sidebar`, `custom`, `overlay`, `storageNamespace: "antigravity-mcp-manager"`, `ipcChannelPrefix: "mcp-manager:"`, `loadOrder: 60`).
- **Refactored** `scripts/electron-hook.cjs` to the `AddonManifest.v1` `mainHook` contract (`activate`, `onWebContentsCreated`, `dispose`) with zero top-level Electron side effects, TOCTOU-guarded `isAllowedRendererUrl` checks, tokenized loopback URL delivery strictly into **Isolated World `999`** (zero World 0 / `sessionStorage` token exposure), and full server/listener/URL cleanup on `dispose()`.
- **Refactored (SOLID 0순위)** the monolithic 745-line `settings-menu-injector.js` into 5 cohesive SRP/OCP/LSP/ISP/DIP modules under `src/adapters/antigravity/renderer/` (`host-runtime.mjs`, `addon-styles.mjs`, `settings-sidebar-mount.mjs`, `customizations-mount.mjs`, `mount-coordinator.mjs`) + zero-dependency deterministic assembler (`scripts/build-renderer.mjs` → `src/adapters/antigravity/addon-renderer.js`).
- **Added** Antigravity **Customizations → MCP Servers** header **MCP Manager** (`MCP 매니저`) button and full-pane `role="dialog"` overlay (`← Back to Customizations`, `✕`, `Esc` focus restoration) using exclusively `addonHost.mountSlot` & `addonHost.injectStyle` with automatic `translate="no"` / `data-addon-host-owner` / `data-agy-no-translate="true"` isolation.
- **Migrated** host language persistence to `storageNamespace` key `antigravity-mcp-manager:lang` with automatic 1-time migration from legacy `agy-mcp-manager-lang`.
- **Stabilized 3-OS CI & Tests**: Extracted shared `test/helpers/cdp-browser.mjs` CDP harness, bounded default concurrency in `scripts/run-tests.mjs` (`--test-concurrency=2`), and expanded test coverage to 28 passing cases (`NMCP-TC-001`–`NMCP-TC-027`, `NMCP-TC-024B`) covering `AddonManifest.v1` schema/parity, `mainHook` Isolated World `999` & TOCTOU guards, and `addonHost.dispose()` teardown.

## 2.1.0 — Native Settings Left-Sidebar Menu Integration & Built-In EN/KO Switcher
- **Added** `src/adapters/antigravity/desktop-server.mjs`: standalone loopback HTTP server reusing 100% of verified `v2.0.0` core (`McpManagerService`), write-jailed FS store, and hardened HTTP security middleware (`127.0.0.1:0` + 256-bit random session token).
- **Added** `src/adapters/antigravity/settings-menu-injector.js`: zero-unsafe-DOM-sink renderer injector that inserts a native-styled **MCP Manager** item directly below **Browser** (or Korean **브라우저**) in Antigravity 2.0's Settings left sidebar with 0px layout shift, preserves the native top-right `X` close button, syncs host font/theme, and toggles the embedded UI iframe without destroying native React nodes.
- **Added** built-in **English / Korean (`EN | 한국어`)** language switcher inside the MCP Manager UI with cross-restart persistence via origin/source-validated `postMessage` to the Antigravity host renderer `localStorage`.
- **Added** `scripts/electron-hook.cjs` & `scripts/install-settings-menu.mjs` (`--install` / `--uninstall` / `--status`) using official `@electron/asar` with an independent marker (`AGY_MCP_MANAGER_SETTINGS_V2`), automatic backup preservation, and zero coupling to `statusbar_autoinject.js`.
- **Polished** Settings-native UI (`host-settings-mode`): 2-column horizontal server rows, segmented `Servers | Raw JSON` pill, crisp `+ Add Server` CTA, collapsible `Quick Paste JSON / URL`, and cleaner `HTTP` / `Stdio` transport badges.
- **Added** comprehensive v2.1.0 tests (`NMCP-TC-021`–`NMCP-TC-026`): real Chromium CDP E2E, `@electron/asar` round-trip & edge cases, `desktop-server.mjs` security & CRUD lifecycle, 100% EN/KO `I18N` dictionary parity, and untrusted `postMessage` rejection (26/26 PASS).

## 2.0.0 — Clean-Slate Native Plugin + UI Sidecar Redesign
- **Removed** all legacy `app.asar` binary patching, `statusbar_autoinject.js` companion bundling, `app_storage.json` hooks, React/Angular DOM scraping, and browser remote-control bookmarklet code (remote web control split to `antigravity-remote-plugin`).
- **Added** official Antigravity 2.0 Plugin manifest (`plugin.json`, `assets/logo.svg`) and `AUX_PANE` UI Sidecar (`sidecars/mcp_manager/sidecar.json`, `main.mjs`, `ui/*`).
- **Added** 100% vendor-independent pure ESM core (`src/core/*`): static validator, secret redactor, declarative smart paste parser, lossless fail-closed JSON/CAS document engine, collision detector, and `McpManagerService`.
- **Added** write-jailed atomic FS store (`src/adapters/fs-config-store.mjs`) with ancestor symlink/junction defense, private backup directory outside `plugins/` (`~/.gemini/config/.mcp-manager-backups/`), mandatory `expectedSha256` CAS, Antigravity 2.0 dialect/paths/loopback-only read-only LS inspector (`src/adapters/antigravity/*`), and hardened `POST`-only Sidecar HTTP middleware (`Host`/`Origin`/`Sec-Fetch-Site`, constant-time `x-sidecar-token`, 1 MiB body cap, strict CSP).
- **Added** cross-OS deterministic test suite (`NMCP-TC-001`–`NMCP-TC-020`, `NMCP-TC-015B` real `sidecars/mcp_manager/main.mjs` + `sidecar_sdk` boot, Windows junction defense, live DOM/IME/Clone-secret-preservation) and 3-OS GitHub Actions CI (`ubuntu-latest`, `windows-latest`, `macos-latest`).
- **Documented** v1.x legacy cleanup/migration and `v2.0.0` → `v1.4.18` rollback procedures in `README.md` and `README.ko.md`.
