Runs immediately in Isolated World `998` with zero `trust approve` required.
  - Official Antigravity Native Sidecar (`sidecars/mcp_manager/main.mjs`, `SIDECAR_UI_ENTRYPOINT_AUX_PANE`) serves as the canonical backend; Settings and Customizations Shadow DOM slots render a zero-`innerHTML` EN/KO Native Sidecar launcher/guide panel by default and automatically upgrade to a live embedded panel if a host loopback `SidecarBridge` URL is supplied (OCP).

- **Upgraded** renderer to `antigravity-native-addon-host` v2 APIs: `mountSlot(slotId, { container })` with Shadow DOM Option B2 host/root resolution, slot-scoped `injectStyle(styleId, css, { slotId })` (zero `document.head` pollution for Shadow slots), `addManagedListener`, and `openModal(slotId, { shadow: true, onClose })` native `<dialog>.showModal()` + `PortalArbiter` overlay preserving host `marginTop`/`zIndex` and capture-phase IME-safe `Escape` LIFO focus restoration.
- **Added** Antigravity **Customizations → MCP Servers** header Shadow DOM **MCP Manager** (`MCP 매니저`) button and full-pane `<dialog>` overlay (`← Back to Customizations`, `✕`, `Esc` focus restoration) with automatic `translate="no"` / `data-addon-host-no-translate="true"` / `data-agy-no-translate="true"` / `data-addon-host-owner` isolation.

- **Stabilized 3-OS CI & Tests**: Upgraded shared `test/helpers/cdp-browser.mjs` CDP harness to mirror `antigravity-native-addon-host` v2.0.0/v2.1.0 (`slot-manager.js`, `style-manager.js`, `modal-portal.js`, `kernel.js`), bounded default concurrency in `scripts/run-tests.mjs` (`--test-concurrency=2`), and verified 28 passing tests (`NMCP-TC-001`–`NMCP-TC-028`, `NMCP-TC-015B`, `NMCP-TC-020B`, `NMCP-TC-020C`) covering `AddonManifest.v2` schema/SOLID parity, Shadow DOM Option B2, `openModal` + `PortalArbiter`, Option A restricted launcher + late URL upgrade, and `addonHost.dispose()` teardown.

## 2.1.0 — Native Settings Left-Sidebar Menu Integration & Built-In EN/KO Switcher
- **Added** `src/adapters/antigravity/desktop-server.mjs`: standalone loopback HTTP server reusing 100% of verified `v2.0.0` core (`McpManagerService`), write-jailed FS store, and hardened HTTP security middleware (`127.0.0.1:0` + 256-bit random session token).
- **Added** `src/adapters/antigravity/settings-menu-injector.js`: zero-unsafe-DOM-sink renderer injector that inserts a native-styled **MCP Manager** item directly below **Browser** (or Korean **브라우저**) in Antigravity 2.0's Settings left sidebar with 0px layout shift, preserves the native top-right `X` close button, syncs host font/theme, and toggles the embedded UI iframe without destroying native React nodes.
- **Added** built-in **English / Korean (`EN | 한국어`)** language switcher inside the MCP Manager UI with cross-restart persistence via origin/source-validated `postMessage` to the Antigravity host renderer `localStorage`.
- **Added** `scripts/electron-hook.cjs` & `scripts/install-settings-menu.mjs` (`--install` / `--uninstall` / `--status`) using official `@electron/asar` with an independent marker (`AGY_MCP_MANAGER_SETTINGS_V2`), automatic backup preservation, and zero coupling to `statusbar_autoinject.js`.
- **Polished** Settings-native UI (`host-settings-mode`): 2-column horizontal server rows, segmented `Servers | Raw JSON` pill, crisp `+ Add Server` CTA, collapsible `Quick Paste JSON / URL`, and cleaner `HTTP` / `Stdio` transport badges.
- **Added** comprehensive v2.1.0 tests (`NMCP-TC-021`–`NMCP-TC-026`): real Chromium CDP E2E, `@electron/asar` round-trip & edge cases, `desktop-server.mjs` security & CRUD lifecycle, 100% EN/KO `I18N` dictionary parity, and untrusted `postMessage` rejection (26/26 PASS).
